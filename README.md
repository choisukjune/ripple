# Ripple

지도 위에서 근처 사람과 채팅하는 웹 서비스입니다. 운영 서버와 데이터베이스가 없고, 대화는 어디에도 저장되지 않습니다.

## 동작 방식

- 브라우저끼리 WebRTC로 직접 연결합니다. 처음에 서로를 찾을 때만 [Trystero](https://github.com/dmotz/trystero)가 공개 Nostr 릴레이를 씁니다.
- 내 좌표를 geohash로 바꿔 방 이름으로 쓰고, 같은 칸 안에 있는 사람끼리 연결합니다.
- 메시지는 브라우저 메모리에만 있다가 새로고침하면 사라집니다.
- "위치 흐리게"를 켜면 좌표를 약 1km 단위로 반올림해서 보냅니다.

## 로컬 실행

```sh
python3 -m http.server 8000
```

`http://localhost:8000`을 창 두 개로 열어 테스트합니다. 위치 권한은 https나 localhost에서만 동작합니다.

## 배포

main 브랜치에 push하면 GitHub Pages가 자동으로 다시 배포합니다.

## 한계

- 회사망처럼 NAT가 엄격한 환경에서는 직접 연결이 실패할 수 있습니다. 해결하려면 TURN 서버가 필요합니다.
- WebRTC 특성상 연결된 상대는 내 IP를 볼 수 있습니다.
- geohash 칸 경계를 사이에 두면 가까이 있어도 다른 방에 들어갑니다.
